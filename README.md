# Arquitecturas Computacionales

Repositorio con las prácticas del curso **P26-LIS2022-1 — Arquitecturas Computacionales** de la Universidad de las Américas Puebla, sección 2, Primavera 2026.

## Contenido

| Práctica | Descripción |
|----------|-------------|
| [Práctica 0](Practica-0/) | Descripción de circuitos combinacionales y secuenciales en VHDL. |
| [Práctica 1](Practica-1/) | Unidad aritmética lógica simple de 4 bits. |
| [Práctica 2](Practica-2/) | ALU RISC-V de 32 bits con dieciséis operaciones del subconjunto RV32I. |
| [Práctica 3](Practica-3/) | Memorias ROM y RAM síncronas de 32 bits para la tarjeta PYNQ Z1. |
| [Práctica 4](Practica-4/) | Máquinas de estado finito: detectores Mealy/Moore de la secuencia 101 y semáforo de doble vía con cruce peatonal sobre la PYNQ Z1. |
| [Práctica 5](Practica-5/) | Procesador RISC-V single-cycle (subset ABC) que evalúa la expresión `x4 = (x1 * x2) + x3`. |
| [Proyecto Final](Proyecto-Final/) | Procesador RISC-V single-cycle ejecutando el juego *Snake* sobre la FPGA Terasic DE10-Lite con salida VGA y entrada por switches. |
